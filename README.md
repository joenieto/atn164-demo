# atn164-demo
TCH ATN164 Demo on PT Personal Devices
This demo created by Joe Nieto demostrates a possible solution for using a patient's personal device
to collect sensitive and confidentail information for the study.

The goal of using a personal device solves many issues including:
1. Device allocation.  The device does not need to be purchased and managed by the hospital.
2. Device management.  Patches and device security are not the responsibilty of the hospital.  Theft or damage are not issues.  The device belongs to the patient.
3. Comfort level.  The device owned by the patient is known to them and they control it.
4. Contamination. The devices not need to be wiped down before beinging handled by another patient.  This is their device and they own it.
